Hermes-Agent Privacy Policy

Last updated: October 20, 2026

Hermes-Agent ("the App") is a personal automation assistant. It is built and operated by an individual developer for use with their own Google account. It is not a commercial service and is not offered to the general public.

1. Google user data the App accesses

With your explicit consent through Google's OAuth screen, the App may access:

  • Gmail (read, modify labels, send): to read, organize and send email on your behalf when you instruct it.
  • Google Calendar: to read and manage calendar events.
  • Google Drive, Docs and Sheets: to read and edit files you ask the App to work with.
  • Google Contacts (read-only): to look up recipients' email addresses.
  • Basic profile information (name and email address) to identify the signed-in account.

2. How the data is used

Google user data is used only to perform the tasks the account owner asks for. It is not used for advertising, not sold, and not used to build user profiles.

3. Storage and security

OAuth tokens and any data the App needs are kept on infrastructure controlled by the developer, protected by access control, and transmitted over encrypted (HTTPS/TLS) connections. Data is retained only as long as needed for the requested task.

4. Sharing

Google user data is not shared with third parties, except where needed to carry out a task you requested (for example, processing your request with an AI model provider), where required by law, or with your explicit consent.

5. Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access and deleting data

You can revoke the App's access at any time at myaccount.google.com/permissions. To request deletion of stored data, contact the developer at the address below.

7. Changes

This policy may be updated. Changes will be posted on this page with a new "Last updated" date.

Hermes-Agent 隱私權政策

最後更新：2026 年 10 月 20 日

Hermes-Agent（以下稱「本應用程式」）是由個人開發者為自己的 Google 帳號打造並使用的自動化助理，並非商業服務，也不對一般大眾提供。

一、存取的 Google 使用者資料

在您透過 Google OAuth 畫面明確同意後，本應用程式可能存取：Gmail（讀取、整理標籤、寄信）、Google 日曆、Google 雲端硬碟／文件／試算表、Google 聯絡人（唯讀），以及基本個人資料（姓名與 email）。

二、資料用途

僅用於執行帳號擁有者要求的工作。不用於廣告、不出售、不建立使用者剖析。

三、儲存與安全

OAuth 權杖與必要資料存放於開發者控管的環境，有存取控制並以 HTTPS/TLS 加密傳輸，僅在完成任務所需期間保留。

四、分享

除為完成您要求的任務（例如交由 AI 模型服務處理）、法律要求或經您明確同意外，不與第三方分享 Google 使用者資料。

五、Google API 服務使用者資料政策

本應用程式對 Google API 所取得資訊的使用與傳輸，遵守 Google API Services User Data Policy，包括 Limited Use 規定。

六、撤銷授權與刪除資料

您可隨時於 myaccount.google.com/permissions 撤銷授權；如需刪除已儲存資料，請來信聯絡。
